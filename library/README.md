# Shared KiCad Library

This directory is reserved for shared KiCad libraries used by projects in this workspace.

## Subdirectories

- `3D/` — 3D model files such as `.step` and `.stp`.
- `footprints/` — Footprint library directories such as `*.pretty/`.
- `symbols/` — Symbol library directories such as `*.kicad_symdir/`.

The directory is currently a library structure placeholder.
