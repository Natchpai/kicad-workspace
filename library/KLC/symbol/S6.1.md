# S6.1 Component Reference Designator (RefDes)

Source: <https://klc.kicad.org/symbol/s6/s6.1/> (KLC 3.0.67, group S6 Symbol Metadata)

The symbol Reference Designator must be filled out appropriately for the particular _type_ of symbol.

The table below provides a list of appropriate RefDes values. If you do not find an appropriate component entry, consult with the KiCad library team.

| Designator | Component Type |
| --- | --- |
| A | removable Sub-assembly or plug-in module |
| AE | Antenna |
| BT | Battery |
| C | Capacitor |
| D | Diode |
| DS | Display |
| F | Fuse |
| FB | Ferrite bead |
| FD | Fiducial |
| FL | Filter |
| H | Hardware (mounting screws, etc) |
| J | Jack, fixed part of a connector pair |
| JP | Jumper / link |
| K | Relay |
| L | Inductor, coil, ferrite bead |
| LS | Loudspeaker or buzzer |
| M | Motor |
| MK | Microphone |
| P | Plug, movable part of a connector pair |
| Q | Transistor |
| R | Resistor |
| RN | Resistor network |
| RT | Thermistor |
| RV | Varistor |
| SW | Switch |
| T | Transformer |
| TC | Thermocouple |
| TJ | Thermal Jumper |
| TP | Test point |
| U | Integrated circuit (IC) |
| Y | Crystal / oscillator |
| Z | Zener diode |
