Template purpose

This template provides a consistent starting point for new KiCad projects. Copy or instantiate the template before beginning a new design, then rename the project files and update the project metadata for the specific product.

The template includes a starter schematic, PCB, project configuration, documentation folders, manufacturing output folders, and locations for project-local symbols, footprints, and 3D models.

Recommended use

  • Create a new project from this template rather than editing the template master directly.
  • Keep native KiCad files as the authoritative design sources.
  • Review the schematic, PCB, libraries, and project settings before releasing a design.
  • Store generated manufacturing outputs and verification records in their designated folders.

Template status: Reusable starting point; project-specific review and verification are required before fabrication.
