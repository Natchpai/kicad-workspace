## Third-party material

Unless a file is known to be the author's own work, treat every file under `library/` as third-party material.

- **3D models** (`library/3D/`): STEP files downloaded from manufacturers or distributors. Each model belongs to its manufacturer.
- **Footprints and symbols** (`library/footprints/`, `library/symbols/`): copied from earlier projects and vendor downloads. Some footprints are based on the official KiCad libraries (for example, files whose description says "generated by kicad-footprint-generator"). The official KiCad libraries are published by the KiCad project under their own license.
- **Vendor files** (`library/_extras/`): a manufacturer download (`10144518-101802LF.zip`) and pin maps taken from manufacturer documents.
- **KLC rule files** (`library/KLC/`): Markdown conversion of the KiCad Library Convention from https://gitlab.com/kicad/libraries/klc (https://klc.kicad.org), by the KiCad library team, dual licensed under GPL-3.0-or-later or CC BY 3.0 or later. Each file links its source page; `library/KLC/README.md` records the version and commit.

Footprints that use `${KICAD10_3DMODEL_DIR}` refer to KiCad's own 3D models. Those models are not stored in this repository.
